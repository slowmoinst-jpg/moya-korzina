# Моя корзина — Android-приложение

Приложение для входа в аккаунты магазинов через WebView на телефоне владельца.

## Зачем

Веб-версия приложения не может авторизовать владельца в магазинах:
- `<iframe>` блокируется `X-Frame-Options` у всех 8 сетей;
- серверный Chromium заблокирован по IP у 4 из 8 (Пятёрочка, Самокат, Лента, Дикси);
- Yandex SmartCaptcha банит серверный вход в Магнит.

Android WebView решает все три проблемы: запрос идёт с телефона владельца,
ограничений iframe нет, `CookieManager` отдаёт все куки включая `HttpOnly`.

## Как работает

1. **«Моя корзина»** — открывает наше приложение. Один раз входите своим номером:
   дальше телефон ходит на сервер с этой сессией. Ни номер, ни секрет в коде не хранятся.
2. Кнопка магазина (Магнит, Пятёрочка, …) — открывает его сайт. Входите как обычно:
   телефон, код из СМС, капча — родной клавиатурой.
3. **«Сохранить вход»** — куки входа уезжают на сервер телом запроса `POST /api/handoff`
   (раньше ехали в адресе и оседали бы в журналах сервера).
4. **«Сохранить акции»** — откройте в магазине страницу своих предложений («Мои скидки»,
   «Персональные предложения») и нажмите: приложение соберёт карточки акций и отправит
   их на `POST /api/store_accounts/sync`. Сервер учтёт их в цене (`app/personal.py`).

## Как собрать

На машине разработчика Android SDK нет, сборка в контейнере на сервере:

```bash
cd android/app
docker build -f Dockerfile.build -t korzina-apk .
docker run --rm -e KORZINA_SERVER=https://<адрес сервера> -v "$PWD:/src" korzina-apk
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

Установка на телефон: нужно разрешить установку из неизвестных источников
(отладочная сборка, подписана отладочным ключом).

## Адрес сервера

Задаётся при сборке: переменная `KORZINA_SERVER` или `-PkorzinaServer=…`. В коде его нет.
Без него приложение соберётся, но на экране скажет, что адрес не задан.

## Чего здесь нет

- Пароли и коды из СМС не перехватываются и не хранятся.
- User-agent не подменяется.
- Отпечаток браузера не трогается.
- Значения кук не показываются на экране.
- Кнопку «заказать» приложение не нажимает.
