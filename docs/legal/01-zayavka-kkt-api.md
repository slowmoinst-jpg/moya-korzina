**2. Наименование продукта, в котором будет использоваться сервис**

«Моя корзина» — приложение для планирования покупок продуктов, которое помогает
пользователю собрать продуктовую корзину дешевле за счёт сравнения цен в разных
торговых сетях и учёта условий его собственных банковских карт.

**3. Где и как будет использоваться сервис**

Сервис используется в одном сценарии: **пользователь загружает в приложение
собственный кассовый чек, чтобы приложение узнало состав его покупки.**

Последовательность действий:

1. Пользователь фотографирует или сканирует QR-код своего кассового чека
   средствами приложения либо вводит реквизиты чека вручную.
2. Приложение обращается к Открытому API проверки чека ККТ и получает состав
   чека — перечень позиций, их количество и стоимость.
3. Полученные позиции используются исключительно внутри приложения: из них
   формируется список покупок пользователя, по нему рассчитывается, в каких
   магазинах эту же корзину можно собрать дешевле.

Ограничения, которые мы соблюдаем:

- обращение к сервису происходит **только по инициативе пользователя** и только
  по тому чеку, реквизиты которого он предоставил сам;
- данные чека **не передаются третьим лицам** и не используются для целей,
  не связанных с работой приложения в интересах самого пользователя;
- сервис используется **на безвозмездной основе**; плата с пользователей за
  обращение к сервису не взимается.

**4. Согласие конечного пользователя**

До первого обращения к сервису приложение получает от пользователя отдельное
информированное согласие на доступ к данным его расчётов и на обработку
персональных данных. Согласие оформляется отдельным действием, включает цель
обработки, состав данных и срок, и может быть отозвано пользователем в любой
момент через интерфейс приложения.

## Что меняется, когда появится юрлицо

До регистрации заявку отправить нельзя: ФНС требует организацию или ИП и
подпись УКЭП. Когда юрлицо появится — заполнить блок 1, получить УКЭП на
руководителя и отправить. Остальной текст менять не нужно.

**ИП тоже подходит** — требование сформулировано как «организация или
индивидуальный предприниматель». Для проверки гипотезы ИП быстрее и дешевле,
и на этот путь он открывает доступ полностью.
