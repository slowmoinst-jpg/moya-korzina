# Где остался пробел и чем искать в сети

Замеры 19.10.2026 (части: [замер привязки и потолок](itogi-zamera-i-potolok-2026-10-19.md),
[единая база](proverka-edinoi-bazy-2026-10-18.md), [дорога к Пятёрочке и Самокату](doroga-k-pyaterochke-i-samokatu-2026-10-18.md)).

## 1. Где именно остался пробел у владельца

По его живой базе (1 159 товаров, 479 покупались хоть раз):

| Сеть, где покупал | Товаров куплено | Привязано настоящим артикулом |
|---|---|---|
| **Самокат** | 367 | **0** |
| Дикси | 65 | 93 |
| **Пятёрочка** | 31 | **0** |
| ВкусВилл | 17 | 35 |
| Лента, Магнит, METRO, Перекрёсток | куплено 0 (привязки из других источников) | 69 / 108 / 137 / 9 |

Куплено и **ни к одной сети не привязано — 352 товара**, из них: **Самокат 275**,
Дикси 34, Пятёрочка 26, ВкусВилл 17. То есть **86 % пробела — ровно те две сети, куда
сервер не пробивается** (Пятёрочка и Самокат), и закрыть их может только телефон
владельца: дорога «найди поиском сети → положи → принеси артикул» уже построена
(приложение 1.13 + наряд с полем `search` + заведение товара в единую базу из адреса
карточки).

## 2. Кто делает привязки: база, а не человек

Из 451 подтверждённой привязки владельца **423 подобрала единая база** (способ `master`)
и лишь 28 — сам человек. Это и есть ответ на «зачем база»: без неё корзину в сетях,
где он не отмечал связи руками, собрать было бы нечем.

Отчёт о качестве (`tools/match_report.py`) на его базе: 451 привязка, **134 с отметками**
(слабо 109, тип 29, вес 1, бренд 1). Читать это как «30 % ошибок» нельзя, и вот почему:
его строки — сокращения чеков, и отметки ставятся в основном из-за них. Примеры отметки
«тип»:

    человек: 'Almette творожный зеленью 60 150 г'
    сеть METRO: 'Сыр творожный Almette с зеленью 60%, 150г'   → «тип: творог ≠ сыр»
    человек: 'Dirol жев рез арб дын кок 13.6 г'
    сеть Магнит: 'Жевательная резинка Dirol Арбузно-дынный к'  → «слабо»

Оба примера — тот же самый товар: Almette и есть творожный сыр, а «Dirol жев рез…» —
это тот же Dirol, только записанный чеком. То есть «сомнительно» здесь значит «посмотри
глазами», а не «связано не то». Это важно сказать владельцу прямо, иначе он не поверит
ни одной цифре экономии.

## 3. Чем телефону искать в сети: полным именем, а не обрубком чека

Поиск сети по строке «Dirol жев рез арб дын кок 13.6 г» не находит ничего — это не слова,
а обрубки. У товара, привязанного к единой базе, есть полное имя
(«Жевательная резинка Dirol Арбузно-дынный коктейль, 13,6 г»), и им сеть ищет нормально.

Поэтому наряд теперь отдаёт телефону для поиска **имя единого товара**, если товар к базе
привязан (`phonecart._query_name`), а если не привязан — строку как написан товар:
выдумывать имя по обрубкам нельзя, по выдуманному слову сеть вернёт чужой товар, а
приложение нажмёт ему «В корзину». Замер: из 301 купленного и не привязанного товара
Самоката и Пятёрочки единый товар есть у **43** — им поиск станет точнее сразу.
