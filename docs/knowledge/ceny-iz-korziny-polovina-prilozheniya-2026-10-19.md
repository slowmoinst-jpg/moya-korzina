# Цены из корзины: половина приложения — 19.10.2026

## Что доделано

Серверную половину сделали в прошлом раунде (`store.set_prices`,
`refresh.note_device_prices`, `accept_report` сохраняет `price`), но приложение цену
**не слало вовсе**. Теперь слает — приложение **1.15** (код 19):

- Сторож корзины (`MainActivity`, `whole()`) собирал «только артикулы и числа, без имён и
  цен». Теперь из чисел берётся ещё и **цена за упаковку**: поле `price` /
  `pricePerUnit` / `unit_price` / `cost` — как названо; если сеть назвала только цену
  строки (`totalPrice`, `sum`), она делится на количество. Цена меньше нуля, ноль или
  больше миллиона не берётся: это не цена упаковки.
- Ответ с корзиной → `window.__kzCart.prices` → `CartRun.prices` → **цена в позиции
  отчёта**. Нет цены в ответе — в отчёте её нет: не выдумываем.
- Наружу, как и раньше, уходят только числа: имена и содержимое корзины не покидают
  страницу (кроме названий позиций наряда, которые и так наши).

## Как это проверено

Живой телефон с непустой корзиной нужной сети — редкий случай, поэтому проверяем
**настоящий JS из исходника приложения** в Node (тот же приём, что у закладки сбора цен):
`tests/test_phone_cart_prices.py` вырезает функцию `whole()` из `MainActivity.java` и
прогоняет её на ответах, какими их отдают сети.

```
{goodId:'111', qnty:2, price:99.9}          -> цена 99.9
{productId:'222', quantity:3, totalPrice:450} -> цена 150.0 (450/3)
{sku:'333', qty:1}                           -> цены нет
{plu:'444', qty:1, price:0}                  -> цены нет (ноль не цена)
{id:'555', qty:1, price:10}                  -> позиции нет: «id» без уточнения —
                                                не артикул, под ним бывает что угодно
{goodId:'1', qnty:1, price:99999999}         -> цены нет
```

Серверная половина проверена `tests/test_device_prices.py` (шесть проверок: цена доходит
до базы, не легшая позиция цену не несёт, ноль и мусор не цена, заглушка, дорога целиком
через `accept_report`, отчёт без цены принимается).

## Чего проверить не удалось

Сквозной прогон на стенде — сборка корзины на живой сети с ценой в отчёте — **не
получился**: окно приложения перестало открывать страницы сетей («Не удалось открыть
веб-страницу» на `magnit.ru`, до этого `chrome-error`). Это состояние окна эмулятора, а
не отказ сети: наш сайт и 5ka.ru в том же окне открывались. Проверить надо будет
следующим заходом (или это случится на живом прогоне владельца — тогда в
`phonecart.last.<сеть>` появятся позиции с `price`).

## Зачем это цели

Цель говорит: «наличие и цены будем получать, формируя корзину в фоне в каждой
подключённой сети». Наличие шло из корзины с прошлых раундов, цены — теперь тоже. Это
особенно важно для трёх сетей, у которых цен нет вовсе: Перекрёсток (158 698 строк),
Vprok (27 551), Монетка (7 772) — 193 021 строка, которую до сих пор нечем было
сравнивать по цене: их обход отдаёт только названия, а корзина владельца — то место, где
цена вообще видна.
