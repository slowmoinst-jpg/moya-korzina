# История цены: теперь видно, дорого ли брать сейчас — 19.10.2026

## Что нашлось

Проверяя, чем база отвечает на вопрос «а не переплачиваю ли я», обнаружил: **не отвечает
никак**. В `chain_prices` у каждого ключа (сеть, артикул, точка) лежала ровно **одна**
строка — при том что ночных снимков было 18–24 (с 27.09). Прежняя цена затиралась каждой
ночью:

```
magnit      7 615 строк | снимков 24
metro      34 959 строк | снимков 18
у каждого (сеть, артикул, точка) — по 1 цене
```

То есть «сколько этот товар стоил вчера» база не помнила. А без этого нельзя сказать ни
«сейчас дороже обычного, подожди», ни «цена упала — бери».

## Что сделано

Таблица `price_history` — строка на **каждое изменение** цены, а не на каждый обход:
рост памяти ограничен числом изменений, а не числом ночей. Пишется в том же месте, где
обновляется цена (`store.upsert_products`): сравнили с прежней, отличается больше чем на
полкопейки — записали.

Два ответа для приложения:

- `store.price_history(chain, sku, point?, days=90)` — что товар стоил раньше, новые первыми;
- `store.usual_price(chain, sku, point?, days=30)` — **медиана** изменений за окно.
  Медиана, а не среднее: одна акция «−50 %» на день не должна сдвигать ориентир.
  Нет истории — `None`, и приложение честно молчит, а не сравнивает с пустотой.

## Проверено

На копии боевого каталога, живым кодом после выкладки:

```
строка: magnit 1000526138 цена: 66.0
истории до: 0
новая цена: 75.9 -> истории после: 1, новая цена в истории: 75.9
обычная цена: 75.9
```

Тесты: `tests/test_price_history.py` — пять проверок (смена цены запоминается, та же цена
дважды не пишется, обычная цена — медиана, без истории ответа нет, история по точкам не
путается). Полный прогон: 1917 passed, 2 skipped. Таблица в боевой базе создана
(`price_history`, 0 строк — заполнится первым же обходом с изменением цены).

## Чего здесь пока нет

- **Приложение этого ещё не показывает.** Данные есть, а надписи «дороже обычного на N %»
  в интерфейсе нет — следующий шаг: в сравнении (`app/compare.py`) добавить к предложению
  пометку, сравнив цену с `usual_price` своего магазина.
- Обход, идущий прямо сейчас, работает на образе, собранном **до** этой правки (он поднят
  отдельным контейнером и пережил выкладку), поэтому история начнёт заполняться со
  следующего обхода на новом образе — то есть с ночи 20.10 или с любой сети, которую
  обойдут после этого.
