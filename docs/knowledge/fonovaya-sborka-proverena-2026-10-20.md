# Фоновая сборка корзины проверена на боевом сервере — 20.10.2026

## Что удалось

Приложение на эмуляторе (боевая сборка, вход владельца) при запуске **само начало
фоновую сборку** во всех подключённых сетях — и это ровно тот пункт цели, который до сих пор
проверялся только на стенде:

```
Корзина в магазинах:
  Магнит      · собираю
  Пятёрочка   · собираю 0 из 4
  Самокат     · собираю 0 из 2
  Лента       · собираю
  Дикси       · собираю 0 из 3
```

Отчёты дошли до боевого сервера **с пометкой background=True**:

```
dixy        at=11:56:16  planned=3  landed=0   background=True
lenta       at=11:56:49  planned=4  landed=0   background=True
pyaterochka at=11:56:55  planned=4  landed=1   background=True
magnit      at=11:58:30  planned=4  landed=0   background=True
```

Отметки телефона (правка, выложенная сегодня) записали это сама:

```
телефон приносил (последнее):
  dixy         отчёт о корзине, 0 шт
  lenta        отчёт о корзине, 0 шт
  magnit       отчёт о корзине, 0 шт
  pyaterochka  отчёт о корзине, 1 шт
  samokat      карточки, 1 шт
```

**База при этом училась:** у Самоката появилось **107 новых строк**, у Магнита 5, у
Пятёрочки 1 — их принесли адреса карточек из отчёта.

## Что это значит

Последний пункт цели — «наличие и цены получаем, формируя корзину в фоне в каждой
подключённой сети, пока человек занимается её формированием» — **работает на боевом
сервере**, а не только на стенде: приложение само обходит сети, присылает отчёты, а база
запоминает товары и наличие.

## Чего пока нет: позиции не ложатся в корзины

`landed=0` у трёх сетей из четырёх — не «всё хорошо». Причины приложение пишет честно:

```
'поиск сети ничего не нашёл за 12 с'          — Лента, Магнит, Дикси (часть позиций)
'на карточке не нашлось кнопки «в корзину»'    — Пятёрочка, Дикси
'поиск сети нашёл не тот товар'                — Магнит, Пятёрочка
```

Имена позиций пришли из чеков и выглядят как «Молоко neo high protein 0 5 безлактозное
ультрапастеризованное 950 г» — поиск сети по такому запросу ничего не находит. То есть
следующий шаг не в сервере и не в базе, а в приложении: **чистить запрос поиска** (марка +
тип + жирность + объём) и **дожидаться кнопки** на карточке дольше 12 секунд.

## Попутно: правка «почему карточек нет» собрана

В приложение добавлено объяснение, когда «Раздел» ничего не находит: `BLOCKER_JS` смотрит
на страницу и говорит словами — «сеть просит выбрать адрес», «сеть просит войти», «сеть
показывает проверку». Собрано и установлено. **Проверить этот случай живьём не удалось:**
переустановка APK сбросила вход, и после входа Самокат был уже не на экране выбора адреса.
Сказать «проверено» про эти сообщения нельзя — проверено только то, что сборка ставится и
приложение работает.

## Состояние эмулятора (для следующей сессии)

Эмулятор `emulator-5554` работает, на нём стоит боевая сборка (v1.15) и выполнен вход под
номером владельца; приложение я остановил, чтобы оно не продолжало действия в сетях без
присмотра. Для стендовых проверок нужна отдельная сборка с
`-PkorzinaServer=http://10.0.2.2:8611`: боевая смотрит на живой сервер владельца.
