# Телефонная дорога проверена от кнопки до базы — 20.10.2026

## Что произошло

На эмуляторе, в боевом приложении (вход владельца), открыл Магнит — настоящую витрину
с товарами и ценами — и нажал «Раздел». Приложение прочло карточки и отправило их на
сервер. Экран сказал сам:

```
Магнит: карточек 21 из 21, новых в базе 0
```

А отметка на сервере (правка, выложенная сегодня) записала приход:

```
magnit: cards, got 21, learned 0, at 2026-10-20T14:34:51
```

## Почему это важно

До сегодня эта дорога была проверена только по частям: серверная дверь — запросом из
контейнера, чтение карточек — тестами и стендом. Теперь проверено **целиком, из живого
приложения на настоящей странице сети**:

```
кнопка «Раздел» → чтение карточек на витрине → POST /api/device/cards
→ телефонная отметка в базе → строки и цены Магнита
```

21 карточка, все уже известны базе (`новых 0`) — то есть цены и наличие у них обновились,
а не завелись дубли. Для сетей, которых сервер не видит (Пятёрочка, Самокат), эта же
дорога — единственная.

## Заодно проверено, что витрина открывается с сохранённым входом

Страница Магнита отрисовалась с товарами и ценами (`Куриное яйцо С2 10шт 71,79 ₽`,
`Сметана Простоквашино 15% 300г 97,99 ₽`) — без ошибок состояния входа. То есть починка
кук (раунд 56) не мешает, а окно показывает живую страницу.

## Что осталось

- Серверное «живое окно» (снимок страницы сети на экране «Кабинеты») вживую всё ещё не
  проверено: для него нужна веб-сессия, а вход по номеру через HTTP сессии не даёт.
- Фоновая сборка корзины упирается в стену по IP (проверено раньше): с эмулятора и сервера
  сети отвечают «Выключите VPN». Читать разделы при этом можно — что сегодня и подтвердилось.
