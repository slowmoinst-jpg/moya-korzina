# Дороги сборки корзины: что работает без телефона — 20.10.2026

Четвёртый пункт цели — «наличие и цены получаем, формируя корзину в фоне в каждой
подключённой сети внутри приложения». Проверил, какие дороги к корзине существуют и что из
них работает прямо сейчас, не дожидаясь телефона владельца.

## 1. Серверная сборка через MCP — работает у двух сетей

`app/connectors/lenta.py::cart_link` и `vkusvill.py::cart_link` (MCP-методы
`storefront_cart_link_create` и `vkusvill_cart_link_create`) построили из боевого контейнера
живые ссылки на готовую корзину:

```
lenta:    https://lenta.com/basket/?share_id=d069aadc-c960-4583-bd74-9885909d90e4
vkusvill: https://vkusvill.ru/mobile?basket&share=62160
```

Содержимое с сервера не проверить: Лента отдаёт этой странице 401, у ВкусВилла корзина
собирается JS уже в браузере. Значит проверка — открыть ссылку в окне владельца: это и есть
поток «Откройте ссылку» на экране корзины. Ссылки создаются на сервере, а не на телефоне —
для этих двух сетей телефон не нужен.

## 2. METRO — серверная дорога есть, но выключена настройкой

`app/connectors/metro_cart.py` умеет писать в корзину METRO по её же API: `read`, `fill`,
`set_count`, `drop`. Но запись требует `connectors.metro_api_token` — токена METRO для
бизнеса. В боевой настройке **его нет**, поэтому `metro_cart.writable() = False`, и сеть
отвечает на запись «Basket not found» (замер 19.09.2026).

Это человеческий шаг: получить токен в кабинете METRO для бизнеса и положить в настройку.
После него METRO сможет собирать корзину сервером — без телефона.

## 3. Телефон — остальные сети, и он честно говорит, что не вышло

Экран «Корзина» боевого приложения (эмулятор, корзина из заказа 8 сентября, Самокат,
4 товара) показывает не «всё хорошо», а правду:

```
Корзина в магазинах
  Магнит       · не вышло
  Пятёрочка    · легло 1 из 4, итог сети не прочитан
  Самокат      · не вышло
  Лента        · не вышло
  Дикси        · не вышло
  Без входа: ВкусВилл, METRO, Перекрёсток
Где дешевле · 4
```

Две вещи здесь важны:

- **Сборка всё-таки садится частично даже с эмулятора** — одна позиция Пятёрочки легла.
  Значит дорога работает, а не «не работает вовсе»; стену по IP она упирает не на каждой
  позиции.
- **Причина у каждой позиции своя**, и она есть в отчёте: стена (`App.phonecart` +
  `WALL_JS` в приложении дают «сеть не пускает этот адрес — показывает «Выключите VPN»»),
  «нет входа», «корзина сети показывает: нет в наличии», «в корзине сети его не видно».
  Строка сети показывает общий итог, подробности — в позициях.

## Что из этого следует

- Для Ленты и ВкусВилла сборку можно делать на сервере (ссылка на готовую корзину).
- Для METRO — можно, но нужен токен METRO для бизнеса (человеческий шаг).
- Для Магнита, Дикси, Пятёрочки и Самоката — только телефон владельца: их витрины закрыты
  для серверного адреса, и с эмулятора они отвечают стеной.

Ни одна из этих дорог не «сломана» — просто у каждой свой предел, и приложение называет его
человеку, а не молчит.
