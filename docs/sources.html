Откуда брать покупки и банковские предложения

Что уже можно подключить, что потребует заявки или договора, а что закрыто и обходится только на стороне пользователя. Проверено поиском по открытым источникам — всё, что требует заявки или договора, помечено отдельно.

Состав покупок даёт только чек Ни один банк не отдаёт, что вы купили: выписка знает магазин и сумму, но не строки. Товары есть только в фискальном чеке — значит, дорога к ним через ФНС или через личный кабинет магазина.
У ФНС есть официальный путь Открытое API проверки чека ККТ работает по заявке и мастер-токену, бесплатно. Оговорка: ФНС пишет, что сервис не предназначен для личного использования — значит, заявку подаёт продукт, а не семья.
Персональных офферов нет ни у кого Ни один из восьми банков не отдаёт наружу персональные предложения клиента. Открытые API ЦБ, обязательные с 2026 года, покрывают счета и выписки — не кэшбэк.

Открытые API Банка России стоит держать в поле зрения, но не ждать от них нашей задачи. В стандарт входят согласие на доступ, счета, баланс, транзакции и выписки. Персональные акции туда не входят, и обязательные сроки сдвинуты до принятия закона.

Что делать

Порядок работ

  1. Подать заявку в ФНС на открытое API проверки чека. Бесплатно, официально, отвечает на главный вопрос: даёт ли сервис состав позиций. Пока заявка идёт, продукт живёт на файлах. Это единственный путь, который не придётся прятать и переделывать.
  2. Сделать приём QR с чека. Фотография кода вместо файла — самый короткий путь для человека. Источник за ним подставляется потом: ФНС по заявке, сторонний сервис по договору или мобильный интерфейс как временная мера.
  3. Расширение браузера для личных кабинетов. Один механизм закрывает сразу и «Мои чеки онлайн», и кабинеты магазинов, и банковские предложения — всё то, что закрыто для сервера, но открыто человеку в его же браузере. Данные не покидают его машину без спроса.
  4. Написать в банки, начиная с Т-Банка. У него единственного есть публичный адрес для запросов об интеграции. Отрицательный ответ тоже результат: он закрывает вопрос и оставляет расширение единственным вариантом.
  5. Карты лояльности и подписки — раньше банковских акций. Подписка с бесплатной доставкой меняет итог не меньше кэшбэка, а данные о ней вводятся руками за минуту и не требуют ничьего разрешения.
