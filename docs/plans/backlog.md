# Бэклог — Моя корзина

## 1. Запасной разборщик вёрстки страниц через DeepSeek Flash (подписка OpenCode Go)

- **Статус:** в бэклоге
- **Контекст:** в исходном Python-коннекторе (`app/connectors/smart_extract.py`) запасной разбор HTML-страниц товаров был настроен на OpenRouter (`openrouter/deepseek/deepseek-v4-flash`, ключ `OPENROUTER_API_KEY`).
- **Цель:** перевести запасной LLM-разборщик вёрстки на **DeepSeek Flash через подписку OpenCode Go** (OpenAI-совместимый API-эндпоинт и ключ подписки через переменные окружения).
- **Область применения:**
  - вызывается только как страховка, когда HTML-страница магазина получена, но штатный парсер/регулярка коннектора не смогли извлечь цену, единицу измерения или наличие;
  - очищает HTML от `<script>`, `<style>`, `<svg>`, `<noscript>` и передаёт компактный фрагмент вокруг цены (до `max_chars` символов);
  - возвращает структурированный JSON (`price`, `unit`, `in_stock`) и логирует фрагмент изменившейся разметки, чтобы починить штатный парсер;
  - не используется для обхода капчи, геоблоков или массового обхода каталога.
- **Переменные окружения (добавить при реализации):**
  - `OPENCODE_GO_API_KEY` (ключ подписки OpenCode Go);
  - `OPENCODE_GO_BASE_URL` (адрес API-шлюза OpenCode Go, если отличается от стандартного);
  - `SMART_EXTRACT_MODEL` (по умолчанию модель DeepSeek Flash из каталога OpenCode Go).
