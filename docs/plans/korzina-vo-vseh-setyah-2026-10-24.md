# Корзина, которая сама собирается во всех сетях — план на 24.10.2026

**Цель владельца (24.10):** корзина повторяется в каждой подключённой сети автоматически, из неё
приходят цены, скидки, спецпредложения и наличие, и уже по ним считается, где что заказать.
Работать должно во всех сетях, не в трёх.

## Принцип

Один маршрут для всех сетей, а не одиннадцать разных:

> телефон владельца (его мобильный адрес, его вход) кладёт корзину и читает страницу корзины →
> отчёт на сервер → цена, скидка, доставка, наличие → `netprice` → «Где дешевле».

Сервер помогает там, где сеть его пускает (METRO, ВкусВилл, часть Магнита), но не наоборот.
Контракт отчёта уже общий для всех сетей (`app/phonecart.py`: `landed`, `page_totals`,
`api_totals`, наличие, цена позиции), поэтому для новой сети нужны: вход, умение найти и положить
товар, умение прочитать «Итого». Расчёт (`app/netprice.py`) от сети не зависит.

## Этапы

Каждый этап закрывается живой проверкой на телефоне/эмуляторе и боевом сервере. Без неё этап
не считается сделанным.

**Этап 0. Видимость.** Расширить `app/humansteps.py` с трёх сетей до всех одиннадцати: по каждой
сети — вход есть, магазин выбран, сколько позиций легло в последнем прогоне, взят ли итог сети,
чем мешает. Тот же вывод — на телефоне в «Настройках». Без этого непонятно, какая сеть на каком
шаге.

**Этап 1. Пятёрочка и Самокат (уже кладут, но мало).** Темп и повтор: пауза между карточками,
повтор после «проверки», добор оставшихся позиций следующим прогоном без нажатия. Цель: легла вся
корзина, а не 2–3 позиции.

**Этап 2. Магнит и Дикси (упираются в вход и точку).** Приложение само распознаёт «выберите
магазин» и «войдите заново» и ставит на телефон одну понятную кнопку «Выбрать магазин в Магните»
/ «Войти в Дикси» вместо тихого «легло 0». После шага владельца сборка продолжается сама.

**Этап 3. Лента.** Гостевая ссылка не даёт ни карты лояльности, ни итога сети. Перейти на тот же
телефонный маршрут, что у остальных (вход владельца, поиск, кладка, чтение «Итого»). Нужно решение
владельца о замене товара (ниже).

**Этап 4. METRO и ВкусВилл.** METRO: либо токен сети (тогда сервер кладёт и читает `total_cost`),
либо тот же телефонный маршрут. ВкусВилл: научить читать «Итого» после ссылки/кладки.

**Этап 5. FixPrice, Перекрёсток, Впрок, Монетка.** Телефонный маршрут через окно сети. Для сетей
без цен в базе корзина становится основным источником цены (`note_device_prices`).

**Этап 6. Автоматичность.** Ежедневная фоновая сборка без нажатия кнопки (ограничения Android на
фон, окно времени, не чаще `rate_limit_rps`, одна сеть за раз), устаревание итога до 6 часов.

**Этап 7. Разбивка на два магазина.** Сеть пишет итог всей корзины, а не доли. Считать долю как
итог сети по её части корзины: «сборка» отдельной корзины на каждую часть разбиения, только когда
разбиение уже выбрано, чтобы не умножать нагрузку.

## Решения владельца

1. **Замена товара.** Лента и другие продают другие линейки. Можно ли в корзине сети класть
   ближайший аналог (по правилам фасовки и бренда) и считать его в итог? Без этого цена в такой
   сети будет только по точным совпадениям.
2. **Токен METRO.** Есть ли у владельца токен сети (личный кабинет METRO)? Нет — идём телефоном.
3. **Живые проверки.** Каждый этап надо проверять на телефоне/эмуляторе и на сервере (`ssh korzina`).
   В облачной сессии Claude Code их нет. Либо проверки запускает владелец командами из памятки, либо
   сессия запускается на машине с эмулятором и ключом `korzina`.
