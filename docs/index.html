Дешевле по строке ≠ выгоднее итогом

Оба чека выше подобрались к порогам почти вплотную — и это не совпадение. Перебор ищет не самую низкую цену на каждую позицию, а самый низкий итог. Поэтому в разбиении есть две строки, которые на первый взгляд стоят не в том магазине.

Уехало туда, где дороже
Пюре детское яблоко-груша
Магнит 45,90 ₽ → ВкусВилл 52,90 ₽

Переплата 7 ₽ держит чек ВкусВилла выше 1 500 ₽. Без неё пропадает кэшбэк 150,94 ₽ — в двадцать раз больше переплаты.

Осталось там, где дороже
Икра лососевая копчёная 180 г
ВкусВилл 154,00 ₽ ✗ Магнит 189,00 ₽

Уберите её из Магнита — чек падает ниже 2 000 ₽ и добавляется доставка 149 ₽. Экономия 35 ₽ оборачивается расходом.

Выгода существует только на уровне варианта целиком. Отсюда и перебор разбиений вместо жадного выбора по строкам:

subtotal = сумма(цена × количество) по позициям, отнесённым в магазин
доставка = 0, если subtotal ≥ порога бесплатной доставки, иначе тариф
кэшбэк   = 0, если subtotal < минимального чека,
           иначе min(subtotal × процент ⁄ 100, остаток лимита карты)
итог     = subtotal + доставка − кэшбэк
вариант  = сумма итогов + штраф × (число магазинов − 1)

Три источника: чеки, магазины, банки

Чтобы расчёт был честным, нужны три вещи: что семья обычно покупает, сколько это стоит сегодня в каждом магазине и какие условия дают карты. Каждая приходит своим путём.

Покупки

Что и в каком количестве берёт семья. Отсюда же берётся сумма, с которой сравнивается экономия.

Чек из PDF от ОФДработает Разбирается построчно: позиция, количество, цена. Весовые узнаются по дробному количеству.
Чек текстомработает Если PDF не читается, подойдёт обычная текстовая выгрузка.
JSON из «Мои чеки онлайн» ФНСработает И от операторов фискальных данных. Суммы там в копейках — пересчитываются в рубли, структура ищется на любой глубине вложенности.
Таблица заказа CSV или XLSXработает Выгрузка из личного кабинета магазина или список, собранный руками. Колонки узнаются по названию, лишние игнорируются.
Выгрузка из ФНС по авторизациив планах Чтобы чеки подтягивались сами, без выгрузки файла руками.

Сайты магазинов

Цены меняются каждый день, поэтому берутся не из памяти, а с сайта — и сохраняются снимками, из которых растёт история цен.

ВкусВиллне отвечает Сайт не отзывается на запросы, поэтому цены берутся из заранее записанного прайса — и это видно в интерфейсе.

Перекрёстокнужен другой путь Обычным запросом не берётся: либо расширение браузера на стороне пользователя, либо договорённость с магазином.

Банки

Кэшбэк решает не меньше, чем цена: процент, лимит за период, минимальный чек и срок меняют ответ целиком.

Свой справочник карт и акцийработает Магазин, процент, лимит, минимальный чек, срок и отметка об активации — вводятся руками один раз.
Загрузка акций из CSVработает Когда карт много, проще залить таблицей, чем вбивать по одной.
Остаток лимита за периодучитывается Выбранный кэшбэк вычитается из лимита: после исчерпания следующие позиции идут уже без скидки, и расчёт это знает.
Персональные предложения из приложений банковв планах Они у каждого свои и живут внутри приложения. Собирать их предполагается расширением браузера — на стороне пользователя и с его ведома.
Карты лояльности и подписки магазиновв планах Подписка с бесплатной доставкой меняет арифметику так же сильно, как кэшбэк.
Промокоды на первый и повторный заказв планах Разовые скидки, которые сейчас приходится держать в голове.
Разбор вблизи

Откуда берётся цена Магнита

Обещанного в спецификации API каталога не существует: /api/catalog/search отвечает 404. Зато сам сайт собирается на сервере — товары и цены уже лежат в разметке страницы, которую отдают браузеру. Их оттуда и читаем.

  1. Поиск. Запрос к странице поиска с названием товара. В ответ приходит каталог: карточки товаров идут в разметке подряд, у каждой в заголовке ссылки лежит полное название, а рядом — цена.
  2. Выбор. Из карточек собираются кандидаты, каждому считается похожесть на ваш товар. Показываются три лучших — какой из них правильный, решает человек, и это решение запоминается.
  3. Артикул. В ссылке на товар стоит числовой артикул. Он и становится ключом: карточка товара открывается по одному артикулу, без остальной части адреса.
  4. Обновление. Дальше цена берётся сразу по артикулу, без поиска. Каждый ответ сохраняется снимком с отметкой времени — так набирается история цен.
поиск   magnit.ru/search/?term=огурцы короткоплодные
        → артикул 1000227406
          «Огурцы короткоплодные тепличные 450г»
          119,99 ₽

цена    magnit.ru/product/1000227406
        → 119,99 ₽

Граммовка вынимается из названия: «450г» в конце превращается в вес, по нему товары сравниваются с допуском ±20 %.

Цена в Магните зависит от конкретного магазина. Без указания кода сайт отдаёт свой по умолчанию — сейчас это Краснодар. Свой код видно в адресной строке после выбора магазина, и он прописывается в настройках: тогда расчёт считает по вашим ценам, а не по чужому городу.

1 запрос в секунду — не больше ответы кэшируются на 6 часов после 3 неудач подряд — резервный прайс до конца сеанса разметка сменилась — тихий откат, а не падение

Последнее важнее, чем кажется: сайт магазина может поменяться в любой день, и тогда разбор перестанет находить цены. Расчёт в этом случае не останавливается — он идёт по резервному прайсу, а в интерфейсе видно, что цены не живые.

Магазины не обязаны отдавать цены роботам: разметка меняется без предупреждения, а часть витрин закрыта намеренно. Поэтому каждый источник изолирован — упавший не мешает остальным, — а юридическая сторона разбора оценивается до того, как продуктом начнёт пользоваться кто-то кроме семьи.

Как получается ответ

Четыре шага от чека до разбиения

  1. Покупки

    Чек PDF от ОФД, JSON из «Мои чеки онлайн» ФНС или таблица заказа из личного кабинета магазина. Весовые узнаются по дробному количеству.

  2. Сопоставление

    «ВК/ПОЛ.Сыр СТРАЧАТЕЛЛА мяг.200г» превращается в эталон и связывается с артикулами магазинов. Подтверждённое не спрашивается снова.

  3. Цены

    Коннектор магазина отдаёт актуальную цену. Снимки не перезаписываются — из них растёт история цен.

  4. Перебор

    Все разбиения корзины между магазинами, для каждого — лучшая карта. Наверх выходят три варианта.
